# lintEffect has moved

Development continues at [Tradedal/biome-effect-linting-rules](https://github.com/Tradedal/biome-effect-linting-rules). New npm releases use [`@tradedal/linteffect`](https://www.npmjs.com/package/@tradedal/linteffect).

This read-only repository preserves the source history and original release tags for `@catenarycloud/linteffect`. The historical source is on the [archive/published-releases branch](https://github.com/OperationalFallacy/biome-effect-linting-rules/tree/archive/published-releases).

All published versions of `@catenarycloud/linteffect` are deprecated with a notice directing users to `@tradedal/linteffect`. Existing versions remain available for installations that depend on them.

Please open issues and pull requests in the Tradedal repository.
